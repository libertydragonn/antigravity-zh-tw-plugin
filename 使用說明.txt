Antigravity 繁體中文化外掛 v1.8.0
================================

這是給 Google Antigravity 桌面客戶端用的繁體中文（臺灣用語）介面外掛包，
由簡體中文版 antigravity-zh-plugin 轉換而來，安裝方式完全相同。
另外內建「對話上下文檢視器與 Token 用量看板」（antigravity-context-viewer），
安裝時一起裝好，面板為繁體中文。
不需要 git、不需要安裝 Python 或 Node.js——解壓後雙擊就能用。

零、開始之前（重要）
--------------------
v1.7.0 的安裝器會「先自檢、再留下」，並自動保護已安裝的第三方外掛補丁：
  - 注入後會自動啟動一次客戶端做冒煙測試；
  - 如果這個版本不相容導致起不來，安裝器會【自動還原官方版本】，
    客戶端仍然可以正常開啟（不會出現「裝了中文化就打不開」的情況）；
  - 還原只接受與當前客戶端版本一致的備份，避免把舊版檔案還原到新客戶端。

一、安裝（約 30~90 秒）
------------------------
1. 解壓本外掛包到任意目錄（路徑建議不含特殊符號）
2. 雙擊「安裝中文化外掛.bat」
3. 指令碼會自動：關閉 Antigravity → 注入中文化 → 寫入上下文看板 → 自檢並啟動客戶端
4. 看到中文介面即安裝成功；若提示「不相容」，說明已自動還原，客戶端不受影響。

一之一、對話上下文檢視器與 Token 用量看板
------------------------------------------
安裝後 Antigravity 右上角頂欄會出現上下文用量、模型額度、生成速度與 Token 用量，
點一下展開面板（繁體中文），可看目前對話上下文、歷史用量熱力圖與費用參考。
  - 不想要看板：雙擊「移除上下文看板.bat」（中文化保留，之後也不會再裝看板）
  - 想裝回看板：雙擊「安裝上下文看板.bat」
  - 看板設定頁裡的「客戶端漢化」請保持關閉，以免和本外掛的繁體翻譯互相覆蓋；
    上下文長度解鎖、提示詞檔位、本地代理等進階功能預設關閉，開啟前請先看說明，風險自負。
  - 來源：https://github.com/elviscjn-cjn/antigravity-context-viewer（MIT）

二、客戶端更新後中文化消失？（這是正常的）
----------------------------------------
官方更新會替換 resources 目錄，中文化必然消失。三種恢復方式任選：

  A. 最快：雙擊「中文化並啟動.bat」
     檢測到未中文化會自動重新注入，然後啟動客戶端（十幾秒）。
  B. 一勞永逸：雙擊「註冊開機自動修復.bat」
     之後每次登入系統都會自動檢查並修復（客戶端更新後無需手動操作）。
     取消：雙擊「取消開機自動修復.bat」。
  C. 雙擊「建立桌面捷徑.bat」，以後從桌面「Antigravity 中文化版」圖示啟動，
     它指向「中文化並啟動.bat」，更新後會自動重新中文化。

三、還原英文原版
----------------
雙擊「還原官方原版.bat」。安裝器會校驗備份版本與當前客戶端是否一致，
版本不一致會拒絕還原（防止客戶端打不開）；此時按提示先重新安裝一次中文化即可重新整理備份。

官方原版備份儲存在兩個地方，客戶端更新清掉一個也不怕：
  - Antigravity\resources\app.asar.bak
  - %USERPROFILE%\.antigravity-zh\backup\app.asar.orig

四、自己加詞條（可選）
----------------------
改 %USERPROFILE%\.antigravity-zh\zh-TW.json 後儲存，介面會自動重翻（無需重新安裝）。

五、macOS / Linux
-----------------
    ./install-macos.sh      # 安裝
    ./restore-macos.sh      # 還原
    ./launch-macos.sh       # 中文化並啟動（客戶端更新後用）
需要系統自帶 python3（macOS/Linux 平臺不做冒煙測試）。

六、出問題了？
--------------
- 安裝日誌：%USERPROFILE%\.antigravity-zh\logs\install-*.log
- 翻譯機制詳解：docs/HOW_IT_WORKS.md
