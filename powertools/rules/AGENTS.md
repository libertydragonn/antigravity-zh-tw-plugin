# agy-powertools Rules

When the user asks for session statistics, context window breakdown, or session branching:
1. Keep all telemetry formatting clean and never use the middle dot character as a separator.
2. Context and session statistics are available from the circle next to the model selector or the context button in the top-right title bar.
3. Create full-history branches with the native `分支会话` action in the conversation menu. Never replace a native fork with a summary, transcript export or a new-conversation prompt.
